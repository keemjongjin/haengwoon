## 프로젝트 소개

여러 블로그 플랫폼을 사용해 봤지만, 항상 아쉬운 기능이나 디자인들이 눈에 밟혀 결국 직접 만들게 되었습니다.
블로그를 제작하면서 평소 음악 디깅을 하는데 기존 평점 사이트들에서도 아쉬운점을 느껴 두 문제를 해결하고자 통합사이트를 제작하게 되었습니다. 이후에도 필요성을 느낄 경우 지속적인 업데이트 예정입니다.

## 기능

- 다크모드 지원
- 반응형 UI: 모바일 환경에서 헤더 폰트크기 축소 및 (max-w-3xl)폭으로 정렬 및 로고를 아이콘으로 전환

### 블로그
- 코드 하이라이팅 지원
- 글 목차 자동 생성(ToC)
- 블로그 글 검색 기능
- Utterances 댓글 기능 지원
- 활동 경력을 보여주는 About 페이지
- 글을 카테고리별로 보여주는 Posts 페이지
- Utterances를 활용한 방명록 페이지
- 진행한 프로젝트를 보여줄 수 있는 projects 페이지

### 음악
- 음악 앨범 및 가수 검색 기능
- 앨범 별 평점기록과 수록곡의 간단한 표시와 가장 좋아하는 곡을 표시할수 있도록 하여 나중에 간편하게 찾아보기 쉽도록 하였다.
- 인사이트: 평점 기록들 데이터를 통해 얻을 수 있는 인사이트를 정리하였다. (장르별 그래프, 평점 분포)
- 익명 댓글 + 스팸 방어
- 음악 정보 API: Spotify API (앨범 정보 및 앨범 전체 재생(관리자 전용))
- 음원 미리듣기 API: Deezer API 활용, 초기에 iTunes API를 활용하였으나. 자동 매칭 정확도나 데이터의 폭이 넓지않아 Deezer API로 변경하였다.
- 하단 재생바 및 여러 미리듣기 대응: 
- 음악 월드컵 기능을 제작하여 내 취향을 큐레이션 하도록 제작

### 관리자
- 통합 관리(앨범평점 CRUD, 블로그 글 노출설정, 데이터 백업, 댓글 관리)
